# Input Data Layout

The scripts read inputs from the local `data/` directory by default. The following table specifies filenames and file formats so users can prepare compatible inputs. The `data/` directory and generated `outputs/` directory are excluded by `.gitignore`.

| Path under `data/` | Used by | Format |
|---|---|---|
| `gene2vec_pairs/*.txt` *(optional)* | Gene2Vec training | Whitespace-separated gene pairs, e.g., `GENEA GENEB` |
| `Gene2vec_0111.txt` | Gene embedding preparation | Gene identifier followed by 200 numeric vector values |
| `TLS_gene_fold5/hj_scaler_mat.csv` | Gene representation and multimodal classification | Samples as rows, genes as columns; numeric preprocessed gene-expression/token values |
| `gene_embeddings.npy` | Gene-level encoder | Aligned NumPy matrix of shape `[number_of_genes, 200]`, generated by `prepare_gene_embeddings.py` |
| `gene_embeddings.genes.txt` | Gene-order validation | One gene symbol per line, generated with the NumPy matrix |
| `GEO2KEGG_pretrain_02211552_27.pth` | gaBERT initialization | PyTorch pretrained checkpoint compatible with the bundled encoder |
| `TLS_gene_fold5/train_foldK.txt` | Fold training | One `SAMPLE_ID CLASS_LABEL` per line |
| `TLS_gene_fold5/test_foldK.txt` | Fold evaluation | One `SAMPLE_ID CLASS_LABEL` per line |
| `cae/foldK/images/train/A/`, `B/` | CAE training | RGB images (JPG/PNG/BMP/PPM) organized by class |
| `cae/foldK/images/test/A/`, `B/` | CAE feature export | RGB images organized by class |
| `cae/foldK/trainAB_img-name_label.txt` | CAE image loading | One `IMAGE_FILENAME.ext CLASS_LABEL` per line |
| `cae/foldK/testAB_img-name_label.txt` | CAE image loading | Same format as training labels |
| `cae/foldK/models/gen_00004000.pt` | CAE embedding export | Generated model checkpoint with generator weights under `ab` |
| `hjImage/foldK_latent_all_model/trainAB_latent_e_gen_00004000.pt_s256_new2.txt` | Multimodal training | `SAMPLE_ID latent: [256 numeric values]` |
| `hjImage/foldK_latent_all_model/testAB_latent_e_gen_00004000.pt_s256_new2.txt` | Multimodal evaluation | Same 256-dimensional latent format |
| `cae/image_id_map.csv` *(optional)* | Image-to-sample matching | `image_filename,sample_id` |
| `original_gene_order.txt` *(optional)* | Explicit gene order | One gene symbol per line |

`K` denotes fold 1–5. Input assets can be obtained or prepared according to the user's data access arrangements. The scripts generate intermediate embeddings, model checkpoints and predictions in the configured local paths.

## Preparation notes

**Gene-expression matrix:** Use a numeric, nonnegative, preprocessed sample-by-gene matrix. The pipeline converts expression values to integer input tokens according to the configured `class_number`. Gene symbols and ordering must match the Gene2Vec positional vectors.

**H&E images:** Use RGB images corresponding to the sample IDs. CAE training/export resize images to `256 × 256` pixels and normalize RGB values. The optional image-ID mapping file supports filenames different from sample identifiers.

**Labels and splits:** Use binary labels (`0` or `1`) and consistent sample IDs across image and gene files. Patient assignments should be disjoint between train and test for each fold.

**Model weights:** Provide a compatible gene-encoder checkpoint when training with pretrained weights. CAE training and fusion training can create their own checkpoints in the configured output directories.
